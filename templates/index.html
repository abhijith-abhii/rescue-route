How the comparison works

The baseline picks the nearest feasible next pantry. The improvement reverses route segments and moves stops between vans only when capacity, unloading windows and return-to-depot limits still hold. Both plans serve exactly the same deliveries. This is a bounded heuristic, not a claim of the best possible route.

All pantries, coordinates and outcomes are synthetic. No live deliveries or real beneficiaries.
